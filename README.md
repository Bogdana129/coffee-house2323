# Coffee House

Сучасний адаптивний сайт затишної кав'ярні **Coffee House** українською мовою. Проєкт зібраний на HTML, CSS і JavaScript з локальним сервером розробки на Vite.

## Про сайт

Coffee House — односторінковий сайт із теплою бежево-коричневою палітрою, фотографіями напоїв та зручною навігацією по розділах. Підходить для презентації меню, контактів і атмосфери закладу на комп’ютері та телефоні.

## Основні можливості

- **Головна** — hero-блок, заклик до дії та короткі переваги кав'ярні
- **Про нас** — історія, фото та статистика
- **Меню** — вкладки «Кава», «Альтернатива», «Десерти» з цінами в гривнях
- **Відгуки клієнтів** — готові відгуки та форма для додавання власного
- **Контакти** — адреса, телефон, графік роботи та форма бронювання столика
- **Галерея** — фото атмосфери закладу
- **Адаптивний дизайн** — коректне відображення на мобільних пристроях і десктопі

## Світла та темна тема

У шапці сайту є **перемикач теми** (іконка сонця / місяця). Одним натиском можна увімкнути **темну тему** в елегантних кавових відтінках; повторне натискання повертає **світлу тему**. Обраний режим зберігається в браузері, тому при наступному відвідуванні тема залишається такою ж.

## Запуск проєкту

1. Встановіть залежності (один раз):

   ```bash
   npm install
   ```

2. Запустіть сервер розробки:

   ```bash
   npm run dev
   ```

3. Відкрийте в браузері адресу, яку покаже термінал (зазвичай [http://localhost:5173/](http://localhost:5173/)).

## Додаткові команди

| Команда           | Опис                          |
| ----------------- | ----------------------------- |
